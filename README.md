# 🧠 XunZi: An AI Biologist for Mechanism-Guided Therapeutic Target Discovery

**XunZi** is an AI biologist that integrates biomedical knowledge and multimodal molecular data to identify disease-modifying targets and generate testable mechanistic hypotheses.

📄 **Paper:**
Huang, X., Qin, J., Tang, F. *et al.*
**XunZi, an AI biologist, reveals disease-modifying targets.**
*Nature Biomedical Engineering* (2026).
https://doi.org/10.1038/s41551-026-01769-6

---

## 🔍 Overview

XunZi integrates logical reasoning with multimodal data fusion for therapeutic target discovery.

It consists of two complementary components:

* **XunZi-M**: a multi-omics learning module that integrates large-scale molecular and biological data to prioritize disease-associated genes.
* **XunZi-R**: a mechanistic reasoning model based on Mistral-7B that synthesizes biomedical knowledge and generates testable gene–disease hypotheses.

> **Note:** Some released scripts and checkpoints use the legacy name **XunZi-L** for the multi-omics module. In this repository, `XunZi-L` and `XunZi-M` refer to the multi-omics scoring component of XunZi.

XunZi was trained using **24.4 million biomedical publications** and **613.6 TB of multisource biological data**, covering **21,008 human genes** and **5,850 diseases**.

---

## ✨ Key Features

* **Biomedical reasoning**
  Continual pre-training and instruction tuning enable mechanistic reasoning over biomedical knowledge.

* **Multi-omics integration**
  Graph-based models integrate large-scale molecular and functional data for disease-target prioritization.

* **Mechanism-guided target discovery**
  XunZi combines target prediction with interpretable and experimentally testable biological hypotheses.

* **End-to-end inference**
  Candidate genes prioritized by the multi-omics module can be passed directly to XunZi-R for mechanistic reasoning.

* **Experimental validation**
  Predictions generated by XunZi were experimentally validated across Parkinson's disease and non-small-cell lung cancer models.

# 🚀 Quick Start

## 1. Installation

Clone the repository:

```bash
git clone https://github.com/biocuckooHXH/XunZi.git
cd XunZi
```

Create a Conda environment:

```bash
conda create -n xunzi python=3.9
conda activate xunzi
```

Install dependencies:

```bash
pip install -r requirements.txt
```

> **PyTorch / GPU note**: install PyTorch first, matching your CUDA environment (see `requirements.txt`).
> For Blackwell GPUs (RTX 50 series, sm_120), use the CUDA 12.8 build with torch >= 2.7:
> `pip install torch --index-url https://download.pytorch.org/whl/cu128`

---

## 2. Download XunZi-R

XunZi-R consists of a biomedical base model and a fine-tuned LoRA adapter.

### XunZi-R-BioPre

Biomedical pretrained base model:

https://huggingface.co/H2dddhxh/XunZi-R-BioPre

Download using:

```bash
hf download H2dddhxh/XunZi-R-BioPre \
  --local-dir ./models/XunZi-R-BioPre
```

### XunZi-R

Mechanistic reasoning adapter:

https://huggingface.co/H2dddhxh/XunZi-R

Download using:

```bash
hf download H2dddhxh/XunZi-R \
  --local-dir ./models/XunZi-R
```

### Configure the base-model path

XunZi-R is a LoRA adapter and requires **XunZi-R-BioPre** as its base model.

After downloading both models, open:

```text
models/XunZi-R/adapter_config.json
```

and update:

```json
"base_model_name_or_path": "/absolute/path/to/models/XunZi-R-BioPre"
```

For example:

```json
"base_model_name_or_path": "/home/user/XunZi/models/XunZi-R-BioPre"
```

---

## 3. Download XunZi Multi-Omics Graph Data

The graph data are distributed separately because the file is too large to host directly in the GitHub repository.

Hugging Face dataset:

https://huggingface.co/datasets/H2dddhxh/XunZi

Download:

```bash
hf download H2dddhxh/XunZi graph_data.zip \
  --repo-type dataset \
  --local-dir ./demo_data
```

Extract the archive:

```bash
unzip ./demo_data/graph_data.zip -d ./demo_data
```

After extraction, confirm that the following file exists:

```text
demo_data/graph_data.pth
```

The pretrained multi-omics checkpoint and gene mapping file are already included in this repository:

```text
demo_data/finetuned_model.pth
demo_data/gene_map.csv
```

# 🧬 Running XunZi

## 4. Run the Multi-Omics Module

The multi-omics module prioritizes genes according to disease-associated molecular features.

Run:

```bash
python demo_xunzi_l.py \
  --graph_data ./demo_data/graph_data.pth \
  --checkpoint ./demo_data/finetuned_model.pth \
  --output_csv results/xunzi_l_predictions.csv
```

The output CSV contains:

```text
GeneID
XunZi_L_score
```

where `XunZi_L_score` represents the predicted disease-relevance score.

A specialized Parkinson's disease kinase checkpoint is also provided:

```text
demo_data/PD_finetune_Kinase_function_model_full.pth
```

It can be used in place of `finetuned_model.pth` when appropriate.

---

## 5. Run XunZi-R

XunZi-R can be used independently for mechanistic reasoning.

First prepare an input CSV such as:

```csv
input
"Summarize mechanisms linking CHK2 to LRRK2 in Parkinson's disease."
"Propose testable hypotheses for IRAK4 in neuroinflammation."
```

Then run:

```bash
python demo_xunzi_r.py \
  --local_dir ./models/XunZi-R \
  --input_csv /path/to/your_inputs.csv \
  --output_csv results/xunzi_r_predictions.csv
```

The default input column is:

```text
input
```

You can specify another column using:

```bash
--text_column COLUMN_NAME
```

XunZi-R can also be loaded directly from Hugging Face:

```bash
python demo_xunzi_r.py \
  --model_id H2dddhxh/XunZi-R \
  --input_csv /path/to/your_inputs.csv \
  --output_csv results/xunzi_r_predictions.csv
```

---

## 6. Run the End-to-End XunZi Pipeline

The end-to-end pipeline first uses the multi-omics model to prioritize candidate genes and then passes selected genes to XunZi-R for mechanistic reasoning.

### Using locally downloaded XunZi-R

```bash
python demo_xunzi.py \
  --graph_data ./demo_data/graph_data.pth \
  --l_checkpoint ./demo_data/finetuned_model.pth \
  --local_dir ./models/XunZi-R \
  --top_k 50 \
  --output_csv results/xunzi_predictions.csv
```

### Using XunZi-R directly from Hugging Face

```bash
python demo_xunzi.py \
  --graph_data ./demo_data/graph_data.pth \
  --l_checkpoint ./demo_data/finetuned_model.pth \
  --model_id H2dddhxh/XunZi-R \
  --top_k 50 \
  --output_csv results/xunzi_predictions.csv
```

The default gene ID mapping file is:

```text
demo_data/gene_map.csv
```

The end-to-end output contains the multi-omics scores together with XunZi-R-generated mechanistic hypotheses.

---

## ⚙️ Useful Inference Options

### Select the top-ranked genes

```bash
--top_k 50
```

### Filter genes by score

Instead of selecting a fixed number of genes, you can use:

```bash
--score_threshold 0.85
```

### Specify a disease

The end-to-end demo uses Parkinson's disease by default.

To analyze another disease:

```bash
--disease_name "Alzheimer's disease"
```

### Generation parameters

Optional XunZi-R generation parameters include:

```bash
--max_new_tokens 256
--temperature 0.2
--top_p 0.9
--do_sample
```
